## 1. Core Positioning & Value Proposition

- **Key Differentiators**:
  - **Zero-Knowledge Privacy**: No tracking, no ads, offline processing.

## 3. Community Engagement & Release Communication

### 1. Release Notes Framework
Every release post should follow this structure:
1. **Headline**: Version number & headline feature highlight.
2. **Major Improvements**: Clean bullet points describing user-visible fixes/features with plain-text status tags ([NEW], [IMPROVED], [FIXED]).
3. **Core Philosophy Reminder**: Reinforce 100% free open-source core commitment.
4. **Call to Action**: Direct links to Google Play, GitHub Releases, and F-Droid.

### 2. Community Channels & Outreach
- **Reddit**: `/r/digitalwellness`, `/r/androidapps`, `/r/selfimprovement`, `/r/privacy`.
- **F-Droid & FOSS Forums**: Highlight zero-GMS decoupled architecture and offline ECDSA licensing.
- **ProductHunt / HackerNews**: Position as privacy-first alternative to predatory subscription blockers.
